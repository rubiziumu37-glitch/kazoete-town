# かぞえてタウン

算数3年「データの活用」（表と棒グラフ）の先取りゲーム。知的固定の特別支援学級向け（テスト版）。
数えて・分けて・表にして、町（水彩の箱庭）を育てる。

- 本番：https://rubiziumu37-glitch.github.io/kazoete-town/
- 入口：ふぁごてか（https://fagoteca.rubiziumu37.workers.dev/）からリンク

## フォルダ
| 場所 | 中身 |
|---|---|
| `index.html` | ゲーム本体（`src/` から作ったもの。直接は直さない） |
| `src/` | 元のファイル。`python3 src/build.py` で `index.html` を作り直す |
| `img/` | 絵（町・家・庭・家具・へや・精） |
| `lib/` | QRを読む部品（jsQR、Apache-2.0。ライセンスは `lib/jsQR-LICENSE.txt`） |

QRを作る部品（qrcode-generator、MIT）は `src/qrcode.min.js` として本体に入っている。

## 記録を消さないための決まり
- 記録は「このURLの、この端末のブラウザ」に保存される（保存の名前 `kazoete-town_save_v1`、先生画面は `kazoete-town_teacher_v1`）
- リポジトリ名・アカウント名を変えない／消さない／Privateにしない
- 保存の形は「足すだけ」。名前や品物のID（H01・G01・K01・R1 など）は変えない
- 子どもの名前・写真はリポジトリに入れない（記録は番号とニックネームだけ）

## 先生画面
- はじめの画面の「せんせい」から。あいことばの初期値は `kazoe`（端末ごとに変更できる）
- あいことばは「子どもがうっかり開かないための目隠し」。コードを読めばわかるので、秘密の守りにはならない
- せっていコード（止める段階・コインの増減）は QR と文字の両方。QR は本番のURLでだけ使える
- **端末が かわった 子を もどす**（2026-11-17）：「そのほか」で、番号・ニックネーム・進んだ ところ（段階と 何こめ まで）・コインを 入れると、その 端末に その子の 記録を 作る（もう ある 番号なら コインを 直し、進みを 足す。へらさない）。もらった 建物は 自動で 入る（置くのは 子ども）。買ったもの・家と 庭・回ごとの 記録は 戻らない。前の 進みと コインは、先生の 端末の「クラスの いちらん」を 見て 入れる
- 子どもの「せんせいに みせる」で出る QR（要約）か文字コード（最近200回分）を、先生画面で読みこむ
